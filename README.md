# American Accent Shadowing

Listen to an American voice, read the stressed syllables, record yourself, and get scored on rhythm, melody and pace. Installable as an app (PWA) on desktop and phone. Recordings and scores stay on your device.

- Add texts: edit `texts.json`, then run `~/.local/pipx/venvs/edge-tts/bin/python build.py`
- Run locally: `./start.sh`
